# DAG meta-model — revised replication package

This package accompanies the revised manuscript:

> Predicting ACE Estimation Error in DAG-Based Causal Inference:
> A Meta-Model Approach with Single-Covariate Adjustment Sets

## Contents

- `analysis/` — generation, estimation, meta-model, tables, and figures.
- `results/raw/` — generated parquet and JSON results.
- `results/tables/` — manuscript tables (CSV) and decision-tree text.
- `results/figures/` — manuscript figures (PDF + JPG).
- `results/compare/` — extension-analysis reports (Markdown/JSON).
- `results/logs/` — run logs supporting console-only metrics (see its README).
- `analysis/requirements.txt` — minimum package requirements.
- `requirements-lock.txt` — exact versions used for the revision.

## File-to-manuscript map

The table filenames retain their original pipeline names. In the revised
manuscript they correspond to:

- `results/tables/table1_feature_importance.csv` → Table 1.
- `results/tables/meta_group_ablation.csv` → Table 2 (grouped permutation
  importance and group removal).
- `results/tables/table2_per_dag_rsquared.csv` → Supplementary Table S.1
  (legacy filename).
- `results/tables/table3_decision_rule.csv` and
  `results/tables/table3_decision_tree_text.txt` → Table 3 (legacy filenames;
  the original E-value table has been removed).
- `results/tables/red_rule_2x2.csv` → RED/GREEN operating characteristics
  (sensitivity, specificity, PPV, NPV) reported in Section 3.4; generated by
  `analysis/red_rule_2x2.py`.
- `results/tables/meta_target_importance.csv` and
  `meta_target_within_stratum.csv` → Supplement §S.10 (relative versus
  absolute target and within-ACE-stratum importance).
- `results/tables/meta_lodo_cv.csv` → Supplement §S.11 (leave-one-DAG-out
  cross-validation).
- `results/tables/meta_domain_check.csv` and `meta_domain_check_features.csv`
  → Supplement §S.6.5 (training-range check). The reusable helper is
  `analysis/meta_domain_check.py:check_domain`.
- `results/tables/meta_classifier_threshold.csv` → Supplement §S.9
  (high-error classification at 5/25/50% thresholds).

Legacy column names are retained for continuity: `median_bias_pp` and
`expected_bias` in `table3_decision_rule.csv` contain AREE values in percent,
and `high_bias_rate` in `table2_per_dag_rsquared.csv` is the high-error rate
(AREE > 5%).

## Reproduce

From the package root:

```bash
bash analysis/reproduce_all.sh          # full pipeline (about 60-70 minutes)
bash analysis/reproduce_all.sh --quick  # tables and figures only
bash analysis/reproduce_all.sh --check  # verify all expected outputs
bash analysis/reproduce_extensions.sh   # extension analyses (about 20 minutes)
```

`--check` verifies every expected output, including JPG figures, the
decision-tree text, and the LPM comparison CSV, and exits non-zero if any file
is missing.

## Environment

statsmodels 0.14.6, scikit-learn 1.8.0, matplotlib 3.10.8, seaborn 0.13.2,

## Notes

- The data-generating process was corrected for M2, M5, M6, and M7; see the
  manuscript's Section 2.2. In particular, M5 now generates X → Z → Y in the
  correct order, and M2 has an exogenous X.
- The E-value calibration script is archived separately and is not part of the
  revised package or of `reproduce_all.sh`.
- The decision rule uses two inputs (`lpm_x_coef`, `n`) and is restricted to
  positive effects; see Section 3.4.
